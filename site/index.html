Tips

Pin commit by:

nix flake lock --override-input nixpkgs \
  github:NixOS/nixpkgs/<commit hash>

Or pin the latest fully built commit automatically:

nix flake lock --override-input nixpkgs \
  github:NixOS/nixpkgs/$(curl -s https://yet.nixoscn.org/l)
